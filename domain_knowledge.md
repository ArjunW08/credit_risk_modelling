## Non Performing Asset(NPA)

Loan that is defaulted(i.e paid by the person).
1. Disbursed Amount : Loan amount give to customer.
2. OSP : Outstanding Principle i.e balanced amount to pay back. OSP should be zero at the end of the cycle.
3. DPD : Days Past Due. Ideally should be zero
4. PAR : Portfolio at risk. OSP when DPD greater than zero.
5. NPA : Loan account whe DPD > 90 days.

## Credit Risk Types in Banking

1. DPD Zero : NDA (Non delinquint account) = No default account = Timely payment EMI.
2. DPD (0 to 30) : SMA1 (Standard Monitoring Account)
3. DPD (31 to 60) : SMA2 (Standard Monitoring Account)
4. DPD (61 to 90) : SMA3 (Standard Monitoring Account)
5. DPD (91 to 100) : NPA
6. DPD (>180) : Written-off (Loan which is not present). This is done to improve the NPA. Loan portfolio quality of bank will be better. Also market sentiment will be good.

## Types of NPA

1. GNPA : Gross NPA(in btw 3-5%) = OSP default
2. NNPA : Net NPA = (0.01 to 0.06%) = Provisioning amount subtracted

Bank quality assess using GNPA value
